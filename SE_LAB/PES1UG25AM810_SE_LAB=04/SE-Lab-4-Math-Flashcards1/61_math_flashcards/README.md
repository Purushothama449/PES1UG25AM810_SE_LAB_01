# Math Flashcards Repair Lab

An interactive mental arithmetic flashcard game built using **Python and Pygame**. This project focuses on debugging arithmetic calculations, implementing a countdown timer, rewarding consecutive correct answers, and generating division problems with exact integer quotients.

## Overview

The game presents randomly generated arithmetic questions. Players enter their answers using a numeric input box and receive immediate feedback. The repaired version includes four improvements: correct arithmetic evaluation, a per-question timer, consecutive-answer score multipliers, and integer division.

## Features

- **Randomized Flashcards:** Generates arithmetic questions using addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Correct Arithmetic Evaluation:** Calculates answers numerically according to the active operator instead of concatenating operands as strings.
- **Countdown Timer:** Displays a timer bar for each question with a 10-second time limit.
- **Timeout Handling:** Registers a missed attempt and resets the streak when the timer expires.
- **Streak Multipliers:** Awards increasing points for consecutive correct answers.
- **Streak Reset:** Resets the streak and multiplier after an incorrect answer or timeout.
- **Exact Integer Division:** Generates division questions that produce whole-number answers without remainders.
- **Division-by-Zero Prevention:** Generates nonzero divisors for division questions.
- **Input Validation:** Prompts players when they submit an empty answer without treating it as a failed attempt.
- **Feedback Messages:** Displays feedback for correct answers, incorrect answers, and timeouts.
- **Score and Attempt Tracking:** Tracks the player's score and submitted or missed attempts.
- **Custom TextBox:** Supports numeric input, cursor interaction, and backspace.
- **Multiple Submission Methods:** Allows answers to be submitted using the Enter/Return key or the SUBMIT button.

## Tasks Completed

### Task 1 — Fix the String Concatenation Bug

The original implementation joined the two operands as text instead of performing the requested arithmetic operation.

**Solution:** Updated `compute_expected_answer()` to evaluate addition, subtraction, multiplication, and division using the active operator.

Example: `8 + 6` now correctly evaluates to `14`, rather than `86`.

### Task 2 — Implement a Per-Question Timer Bar

Each question has a **10-second countdown timer** displayed as a visual bar.

**Solution:** Added timer state, elapsed-time tracking, timer-bar rendering, and timeout handling. When time runs out, the game registers a missed attempt, resets the streak, and advances to another question.

### Task 3 — Implement Consecutive Correct Streak Multipliers

Players earn more points by answering consecutive questions correctly.

**Scoring example:**

| Consecutive correct answer | Points earned | Total score |
|---|---:|---:|
| First | +1 | 1 |
| Second | +2 | 3 |
| Third | +3 | 6 |
| Fourth | +4 | 10 |

**Solution:** The multiplier increases with each consecutive correct answer. An incorrect answer or timeout resets the streak and multiplier to their starting values. Submitting an empty answer does not count as a failed attempt.

### Task 4 — Add Division with Clean Integer Quotients

Division was added to the randomized operator pool.

**Solution:** Division questions are generated by selecting a nonzero divisor and an integer answer, then calculating the dividend as their product. This ensures that division questions have exact integer answers without remainders.

Examples:

- `24 / 6 = 4`
- `30 / 5 = 6`
- `36 / 9 = 4`
- `48 / 8 = 6`

## Installation and Setup

### Prerequisites

- Python 3.10 or newer
- Git
- Internet access to clone the repository and install Pygame

### Step 1 — Clone the Repository

Clone the team repository directly, as recommended by the lab instructions.


```bash
python -m pip install pygame
```

```powershell
py -m pip install pygame
```

### Step 3 — Run the Game

```bash
python main.py
```

On Windows, you can alternatively run:

```powershell
py main.py
```

## How to Play

1. Start the game using `python main.py`.
2. Read the arithmetic question displayed on the flashcard.
3. Enter your numeric answer in the input box.
4. Press **Enter/Return** or click **SUBMIT**.
5. Observe the feedback, score, attempt count, timer, and streak multiplier.
6. Answer consecutive questions correctly to increase your score multiplier.
7. Submit answers before the timer expires to avoid a missed attempt.

### Controls

| Control | Action |
|---|---|
| Numeric keys | Enter an answer |
| Backspace | Delete a digit |
| Enter / Return | Submit the answer |
| SUBMIT button | Submit the answer using the mouse |
